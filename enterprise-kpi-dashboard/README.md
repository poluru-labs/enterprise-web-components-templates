# Signal KPIs

Executive scorecard workspace for **Clearline Holdings**. Light theme, brand `#DD0303`.

The canvas starts **full width**. Use the menu control (or `⌘\`) to open a simple sidebar; hide it again to return to full width.

Demo people use the surname **Poluru**. The product name is Signal.

## Run

```bash
npm install
npm run dev
```

Opens at [http://localhost:5178](http://localhost:5178).

## Pages

Overview, Scorecards (and scorecard detail), Goals, Trends, Teams, Alerts, Reviews, Benchmarks, Reports, Settings.

Jump with `⌘K` or the header search.
